The Uncle Whisperer

A relative sent you a message before Thanksgiving dinner, and you do not know how to answer it. Paste the message here. The agent tells you what is really bothering the relative who wrote it, what you should not answer, and one sentence you can send back.

1. Paste the message your relative sent you

No message at hand? Press one of these three buttons, and the agent fills the form with a sample message:

2. Relatives the agent remembers for you

The agent keeps a short note about each relative on its own computer. When the same relative writes to you again, paste the new message, and the agent compares it with the earlier one.
